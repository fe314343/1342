# 解憂雜貨店

七頁互動時光旅程：店面、今夜的邀請、前言、小說式故事、QR Code、結語與四季大典。

## 使用

直接以瀏覽器開啟 index.html；writing.html 是保留的明信片寫信工具，草稿與信件只保存在使用者的瀏覽器。

## GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save。

所有網站檔案放在根目錄，不需要安裝套件或建置。啟用後請以 Pages 顯示的網址為準。

## 修改

- index.html：七頁文字與 QR Code 區域
- journey.css：外觀與響應式排版
- journey.js：翻頁導覽與五章故事
- letter-qr.png：第五頁 QR Code 圖片
- shop-front-realistic-v1.png：AI 生成店面圖片
- writing.html / postcard.js：明信片與 QR 文字工具

第三方 QR 編碼程式的授權見 qr-license.txt。

此儲存庫是網站程式碼的同步副本。原本 ChatGPT Site 和 GitHub 的修改不會自動雙向同步。
